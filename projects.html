Build notes & gotchas

The honest part: what broke, and what each project taught me.

🔒 Lock studio: stale server danger

A stale dev server once re-wrote a broken LockView.qml and killed my lock screen. Fix: relaunch the app (it takes over port 8731) before clicking Apply, plus backup/restore on every write.

🐳 Homelab: permissions & APIs

Containers couldn't see each other's volumes until user/group IDs were mapped correctly, and the indexer needed its API key re-issued. Lesson: check identity and credentials before blaming the network.

🚗 LubeLogger: honest records

A maintenance tracker only works if the records are honest: every fuel-up and repair dated, so cost-per-mile stays accurate and nothing gets forgotten.

📋 Booking widget: mobile first

Designed phone-size first, then scaled up, date pickers and vehicle cards that stay usable on a 360px screen work everywhere.

🌐 This portfolio: no frameworks

Hand-written HTML/CSS/JS across five pages: shared stylesheet, guarded scripts per page, scroll-scrub motion, and deploys to both GitHub Pages and NJIT's server with zero build step.

📚 What I'd do differently

Start the README on day one, screenshot as I go, and pick image dimensions before writing layout code, retrofitting sizes cost the most time.
